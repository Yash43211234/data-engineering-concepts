# ETL – Transformations

## What is Transformation?

**Transformation** means changing source data into a **clean, uniform, and required structure** before loading it into the Data Warehouse.

### Main purposes

1. **Uniformity** → Make data consistent across different sources.
2. **Restructuring** → Make columns and records fit the required structure.

```text
Source Data → Transformation → Clean & Uniform Data → Data Warehouse
```

---

## Common Transformations

### 1. Data Value Unification

Different systems may use different values for the same meaning.

Example:

```text
Zone 1 → status = Active / Inactive
Zone 2 → active = Y / N
```

We convert them into one common format.

**Goal:** Same meaning → Same value format.

---

### 2. Data Type & Size Unification

The same column may have different data types or sizes in different systems.

Example:

```text
Zone 1 → name VARCHAR
Zone 2 → name CHAR(35)
```

We choose a common datatype and size for the Data Warehouse.

**Goal:** Consistent datatype and size.

---

### 3. Deduplication

Remove duplicate records coming from different sources.

Example:

```text
Zone 1 → Customer A
Zone 2 → Customer A
```

After deduplication:

```text
Customer A → One record
```

**Goal:** Avoid duplicate data in the Data Warehouse.

---

### 4. Drop Columns

Remove columns that are not required in the Data Warehouse.

Examples:

* Unnecessary audit columns
* Temporary columns
* Unused source columns

---

### 5. Drop Records / Rows

Remove records that are not required according to business rules.

```text
Source → Filter unwanted records → Process remaining records
```

> Not every unwanted employee/customer record should be deleted. Sometimes we simply mark it as `Inactive`.

---

### 6. Handling NULL / Missing Values

If an important value is missing, we can:

**Option 1:** Drop the record.

**Option 2:** Fill the missing value using a suitable value.

Example:

```text
NULL sales amount → Average sales amount
NULL location → Most frequently used location
```

The method depends on the business requirement.

---

# Interview Questions

### Why do we perform transformation?

To make source data **clean, consistent, and properly structured** before loading it into the Data Warehouse.

### Common transformations?

* Data value unification
* Data type and size unification
* Deduplication
* Dropping columns
* Dropping/filtering records
* Handling NULL values

### What is deduplication?

Removing duplicate records so that the same data is not stored multiple times.
